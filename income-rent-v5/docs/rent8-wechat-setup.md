# rent8_wechat V6 API 配置

## 快速配置步骤

### 1. 修改 API 端点

编辑 `miniprogram/app.js`，找到：

```javascript
const apiUrl = "http://rent81.test/";
```

修改为：

```javascript
const apiUrl = "http://192.168.9.2:8788/";
```

> 如果你的電腦 IP 不是 192.168.9.2，請替換為你的實際 IP

### 2. 获取你的電腦 IP

在 PowerShell 中运行：

```powershell
ipconfig | findstr "IPv4"
```

找到類似 `192.168.x.x` 的地址。

### 3. 微信开发者工具设置

1. 打开微信开发者工具
2. 导入项目 → 选择 `rent8_wechat` 文件夹
3. 修改 AppID（如果没有，选择测试号）
4. 菜单：工具 → 构建 npm
5. 点击「详情」→ 「本地设置」→ 勾选：
   - ✅ 不校验合法域名
   - ✅ 不校验 TLS 版本

### 4. 登录测试

- 用户名：`morefun886`
- 密码：`Mf848886`

### 5. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 登录失败「用戶不存在」 | 检查 V6 API 是否运行：`curl http://localhost:8788/api/health` |
| 网络连接失败 | 检查 IP 地址是否正确，手机/模拟器能否访问電腦 |
| 數據為空 | 正常，需要先添加租客和賬單數據 |

## 测试连接

在电脑浏览器中打开：

```
http://192.168.9.2:8788/api/health
```

應該看到：

```json
{"status":"ok","version":"6.0.0","timestamp":"..."}
```

如果看到，说明 API 正常运行。
